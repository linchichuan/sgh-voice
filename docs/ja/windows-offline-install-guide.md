# SGH Voice Windows オフライン版（日本語）導入手順書

対象：医療機関の情報システムご担当者さま
対象ファイル：`SGHVoice-Windows-<バージョン>-x64-unsigned.exe`（以下「インストーラー」）

> **本書の対象はテスト版です。** インストーラーにはデジタル署名がなく、実機での受け入れ確認（マイク、ショートカット、電子カルテへの文字入力、一般ユーザー権限での動作）は完了していません。評価目的でのみご利用ください。

---

## 1. 製品の概要

- 日本語の音声を、このパソコンの CPU だけで文字に変換します。
- 音声認識モデルはインストーラーに含まれています。**インストール時も利用時も、インターネット接続は不要**です。
- クラウド認識、API キー、利用登録、モデルの追加ダウンロードはありません。
- 認識結果は画面上で確認・修正してから、コピーまたは入力先へ送ります。

本製品は文字起こしを補助するソフトウェアです。診断・治療の判断を行うものではありません。薬剤名、用量、単位、否定表現などは、必ず担当者が元の発言と照合してください。

## 2. 動作環境（目安）

| 項目 | 内容 |
|---|---|
| OS | Windows 10（22H2）／Windows 11、64 ビット（x64） |
| CPU | x64、SSE4.1 対応（GPU は不要） |
| メモリ | 8 GB 以上を推奨（開発上の目安であり、実測した最低要件ではありません） |
| 空き容量 | 4 GB 以上（インストール後の使用量は約 1.7 GB） |
| 権限 | インストールには管理者権限が必要です。利用は一般ユーザーで行えます（実機確認は未了） |
| ネットワーク | 不要 |
| マイク | Windows 標準ドライバーで動作する USB マイクなど |

ARM 版 Windows、VDI／リモートデスクトップ上の電子カルテへの入力は、現時点では動作を確認していません。

## 4. 受け取ったファイルの照合

USB メディアまたは Google ドライブで受け取ったファイルは、院内の持ち込み手順（申請・ウイルス検査など）に従って取り扱ってください。

インストール前に、インストーラーの SHA-256 値が `SHA256SUMS.txt` の値、および弊社が別経路（書面またはメール）でお知らせする値と一致することを確認してください。

```powershell
Get-FileHash -Algorithm SHA256 .\SGHVoice-Windows-<バージョン>-x64-unsigned.exe
```

一致しない場合はインストールせず、弊社までご連絡ください。

## 5. インストール

1. 管理者アカウントでインストーラーを実行します。
2. 署名がないため、Windows SmartScreen などの警告が表示される場合があります。**セキュリティ機能を無効にせず**、院内の規程に従って実行可否をご判断ください。
3. 既定のインストール先は `C:\Program Files\SGHVoice` です。
4. 完了すると、スタートメニューに「SGH Voice」が登録されます（デスクトップのショートカットは任意）。

一度インストールすれば、そのパソコンのすべての Windows アカウントで利用できます。

### サイレントインストール（一括展開する場合）

```powershell
.\SGHVoice-Windows-<バージョン>-x64-unsigned.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /LOG="C:\Temp\sghvoice-install.log"
```

## 6. 初回起動と使い方

1. 「SGH Voice」を起動すると、内蔵の音声モデルが改ざん・破損していないかを確認します。初回は数秒から数十秒かかります。2 回目以降は短時間で終わります。
2. 「録音してプレビュー」を押すか、ショートカット **Ctrl + Alt + F9** で録音を開始・停止します。**Ctrl + Alt + F10** で取り消します。
   - 1 回の録音は最長 60 分です（診察 1 回分を想定）。録音中は経過時間が表示され、60 分に達すると自動で停止して文字起こしします。無音が 10 分続いた場合も自動で停止します。
   - 30 秒を超える録音は、録音ファイルと同じ方法（無音部分を飛ばし、話の区切りごとに改行）で処理し、進み具合を表示します。処理時間は録音時間と同程度です。
   - マイクに入った音声だけを記録します。オンライン診療でヘッドセットを使う場合、相手の声は記録されません。
3. 認識結果が表示されます。内容を確認・修正してから「テキストをコピー」を押し、目的のアプリに貼り付けます。
4. 入力先への自動入力は、既定ではオフです。設定で有効にした場合も、入力先に正しく入ったかを必ず確認してください。

### 録音ファイルの文字起こし

スマートフォンや IC レコーダーで録音したファイルも文字にできます。

1. 「音声ファイルを文字起こし…」を押し、WAV または MP3 ファイルを選びます。
2. 進み具合が画面下部に表示されます。処理時間は録音時間と同程度です（パソコンの性能により異なります）。「キャンセル」でいつでも中止できます。
3. 完了すると、話の区切りごとに改行された文章が表示されます。内容を確認し、「テキストをコピー」または「テキストを保存…」（UTF-8 のテキストファイル）を使用します。

- 対応形式：WAV、MP3（1 ファイル 3 時間・2 GB まで）。iPhone のボイスメモなど M4A 形式は、現時点では MP3 に変換してから読み込んでください。
- 元の録音ファイルは送信も変更もしません。変換用の一時ファイルは処理後に削除します。

「内蔵の音声モデルが見つかりません」「破損しているか不完全です」と表示された場合は、元のインストーラーで再インストールしてください。

## 7. データの取り扱い

| データ | 保存場所・扱い |
|---|---|
| 録音音声 | 一時ファイルとして作成し、認識後に削除します。 |
| 認識結果 | 画面にのみ表示します。履歴の保存は既定でオフです。 |
| 設定・（有効時の）履歴 | 各ユーザーの `%LOCALAPPDATA%\SGHVoice` |
| 音声認識モデル | `C:\Program Files\SGHVoice\models`（読み取り専用） |

本製品は、録音・認識結果・設定を外部へ送信しません。弊社が院内のデータを受け取ることもありません。

## 8. アンインストール

「設定」→「アプリ」→「SGH Voice」→「アンインストール」を選びます（管理者権限が必要です）。プログラムとモデルは削除されます。各ユーザーの `%LOCALAPPDATA%\SGHVoice` は自動では削除されないため、不要な場合は手動で削除してください。
