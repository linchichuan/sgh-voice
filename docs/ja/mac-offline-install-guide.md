# SGH Voice Medical（Mac オフライン版・日本語）導入手順書

対象：医療機関の情報システムご担当者さま
対象ファイル：SGHVoice-macOS-<バージョン>-arm64-unsigned.dmg

> **テスト版です。** Apple の公証（ノータリゼーション）を受けていないため、初回起動時に macOS の確認が必要です。実機での受け入れ確認（マイク、電子カルテへの貼り付け）は完了していません。評価目的でのみご利用ください。

## 1. 概要

- 日本語の音声を、この Mac の中だけで文字に変換します。インターネット接続は不要です。
- 30 秒を超える録音や音声ファイルの取り込みの後、内蔵の言語モデルが SOAP 形式の下書きを作成します（この Mac の中で処理）。
- 下書きは誤りを含むことがあります。必ず医療従事者が文字起こしと照合して確認してください。診断・治療の判断は医師が行います。

## 2. 動作環境（目安）

- Apple シリコン（M1 以降）の Mac、macOS 13 以降
- メモリ 16 GB 推奨（8 GB でも動作する見込みですが未確認）
- 空き容量 10 GB 以上（インストール後約 4.6 GB）
- Intel Mac には対応していません。

## 3. インストール

1. DMG を開き、「SGH Voice Medical」を「Applications」フォルダーへドラッグします。
2. 初回は「アプリケーション」フォルダーで「SGH Voice Medical」を **右クリック（または Control + クリック）→「開く」** を選びます。
3. 「開発元を検証できません」と表示された場合は、「システム設定」→「プライバシーとセキュリティ」の下部にある「このまま開く」を押し、管理者パスワードを入力します。
4. マイクの使用許可を求められたら「許可」を選びます（音声は外部に送信されません）。

## 4. 使い方

- 「録音してプレビュー」で録音を開始・停止します（最長 60 分）。Mac 版ではショートカットキーは使えません。
- 文字起こしの後、SOAP 下書きが自動で作成され、クリップボードにコピーされます。内容を確認してから、電子カルテで ⌘V で貼り付けてください。
- 「音声ファイルを文字起こし…」で WAV／MP3 ファイルを読み込めます（M4A は MP3 に変換してください）。

## 5. データの取り扱い

- 録音音声・SOAP 作成時の入力は一時ファイルとして作成し、処理後に削除します。
- 設定は `~/Library/Application Support/SGHVoice Medical` に保存されます。履歴の保存は既定でオフです。
- 録音・認識結果・設定を外部へ送信しません。

## 6. アンインストール

「アプリケーション」フォルダーから「SGH Voice Medical」をゴミ箱へ移動します。設定を消す場合は `~/Library/Application Support/SGHVoice Medical` も削除してください。
