# SGH Voice App Store artifacts

This directory contains copy-ready App Store Connect metadata for SGH Voice iOS.

- `Metadata/ja-JP/` contains public Japanese storefront metadata.
- `Review/review_notes.template.txt` is a draft only. It must not be submitted while any `［提出前入力` placeholder remains.
- `Review/beta_description.txt` and `Review/what_to_test.txt` describe the planned Evaluation Access flow. They become valid only after that flow is implemented and verified in the submitted build.
- Screenshots must be captured from the submitted build and placed under `Screenshots/` only after checking that no API key, account identifier, patient information, or other personal data is visible.

The detailed source and checklist are in `docs/app-store/SGHVoice_AppStore_Submission_JA.md`.
